#### what i've been working on

[nixos-gui](https://github.com/flooryyyy/nixos-gui) is my final-year project and an experimental Python tool for browsing and editing NixOS configuration. it evaluates NixOS options and package metadata locally, lets you queue changes for review, then can dry-build, test, or switch a configuration. i built it to help beginners configure their NixOS systems. the first version was made under a university time crunch, so i'd like to rewrite it properly when i have more time.

outside my own projects, i've contributed fixes to [Hermes Agent](https://github.com/NousResearch/hermes-agent) and other tools i use daily. that work has taken me through NixOS build issues, terminal UI behaviour, memory handling, request lifecycles, and integrations between different tools and services. i enjoy the point where a vague problem becomes something reproducible and fixable.

at home, i maintain NixOS-based infrastructure and self-host Docker Compose services behind Caddy and Tailscale. i run local language models with llama.cpp, experiment with inference settings, and run repeatable model evaluations. i also like seeing what new services i can self-host and how the pieces fit together when something breaks.
