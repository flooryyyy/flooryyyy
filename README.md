#### what i've been building

[nixos-gui](https://github.com/flooryyyy/nixos-gui) is my final-year project and an experimental Python tool for browsing and editing NixOS configuration. it evaluates NixOS options and package metadata locally, lets you queue changes for review, then can dry-build, test, or switch a configuration. i built it to help beginners configure their NixOS systems. it is still experimental, and i'd like to revisit its design when i have more time.
